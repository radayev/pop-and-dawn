# Pop & Dawn

Web prototype for Team 4's NYU midterm, *Building an AI-First Snack Company*: Pop & Dawn Sea Salt Dark Chocolate Popcorn Crunch, a plant-based popcorn cluster breakfast cereal.

The site is a landing page, a product showcase, a cart, and a checkout simulation. The checkout takes no real orders or payments.

It was built with an agentic AI coding assistant (Claude Code). The team reviewed it.
